Página web de **Mira Productions**, estudio de Minecraft Java dedicado a la creación de modificaciones y eventos a tu gusto.

Les entrego todos los archivos para que hagan uso del código **libremente** y lo puedan subir al host de su preferencia.

## Cómo editar la página

Casi todo lo editable está en un solo lugar: el bloque **CONFIGURACIÓN DEL SITIO** al inicio del `<script>` de `index.html`. Ahí se cambian textos, enlaces, novedades, proyectos, servicios, tienda y correo de contacto, sin tocar el resto del código.

- **Novedades:** se agregan en la lista `NEWS`. Las instrucciones están en los comentarios justo arriba.
- **Tienda:** actualmente usa Ko-fi.
- **Imágenes y música:** van en la carpeta `assets/`. Los nombres deben coincidir exactamente, incluidas mayúsculas y minúsculas.

## Importante: formulario de contacto

El formulario envía los mensajes al correo del studio usando **FormSubmit**. **Cada vez que se cambie de host o de dirección de la página, FormSubmit pedirá verificar el correo de nuevo.** Para hacerlo:

1. Publiquen la página en el nuevo host.
2. Manden un mensaje de prueba desde el formulario.
3. Confirmen el enlace que llegue al correo del studio (revisen también spam y Promociones).

Mientras no se confirme, los mensajes no llegarán.
